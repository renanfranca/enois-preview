Service lifecycle tests use real Git and H2 with identifiable service adapter fixtures; those fixtures do not constitute a full running Spring backend holding the live H2. The new publisher tests use a real local bare Git remote and simulated GitHub/GHCR/Cloudflare transports, including lost acknowledgements. Validation gate negative cases explicitly simulate public transport. Existing Miniflare tests exercise the local Cloudflare runtime and SQLite Durable Objects. None of those simulations establish actual platform permissions or a successful remote publication.

The fictional example was prepared from pinned public application repositories in separate empty destinations. `VerifyExample` checks actual rows and hashes canonical application data separately from Flyway execution timestamps and H2 page layout. The image build installs public dependencies without mounting the operator's credential files, rebuilds and packs the design system, verifies frontend consumption of that tarball, runs backend behavior tests, runs frontend typecheck/tests/build, and records packaged seed/media hashes. Local browser checks use Chromium at 1280 px and 390 px; the latter is mobile emulation, not a physical device.

Credentials are written only to private runtime/evidence files with mode 0600, inside directories with mode 0700. Shareable JSON evidence contains IDs, checks, hashes and dimensions, not passwords or cookies. Do not copy `*credentials.json` into this repository or public artifacts.
